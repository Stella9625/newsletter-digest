Pretext

Pretext solves the problem of calculating the height of a paragraph of line-wrapped textwithout touching the DOM. The usual way of doing this is to render the text and measure its dimensions, but this is extremely expensive. Pretext uses an array of clever tricks to make this much, much faster, which enables all sorts of new text rendering effects in browser applications.

Pretext 解决了在不触碰 DOM 的情况下计算一段换行文本（line-wrapped text）高度的问题。通常的做法是渲染文本并测量其尺寸，但这计算成本极高。Pretext 运用一系列巧妙的技巧大幅提升速度，从而能够在浏览器应用（browser applications）中实现各种全新的文本渲染效果。

以下是一个演示，展示了这项技术能够实现的效果：

The key to how this works is the way it separates calculations into a call to aprepare()function followed by multiple calls tolayout().

其工作原理的关键在于将计算分离为对 prepare() 函数的调用，以及随后对 layout() 函数的多次调用。

Theprepare()function splits the input text into segments (effectively words, but it can take things like soft hyphens and non-latin character sequences and emoji into account as well) and measures those using an off-screen canvas, then caches the results. This is comparatively expensive but only runs once.

prepare() 函数将输入文本分割为若干片段（实质上是单词，但也能处理软连字符（soft hyphens）、非拉丁字符序列和表情符号等），并使用离屏 canvas（off-screen canvas）进行测量，然后缓存结果。这一步骤相对昂贵，但仅执行一次。

Thelayout()function can then emulate the word-wrapping logic in browsers to figure out how many wrapped lines the text will occupy at a specified width and measure the overall height.

随后，layout() 函数可以模拟浏览器中的自动换行（word-wrapping）逻辑，计算出文本在指定宽度下将占据多少行，并测量整体高度。

The way this is tested is particularly impressive. The earlier testsrendered a full copy of the Great Gatsbyin multiple browsers to confirm that the estimated measurements were correct against a large volume of text. This was later joined bythe corpora/ folderusing the same technique against lengthy public domain documents in Thai, Chinese, Korean, Japanese, Arabic, and more.

其测试方式尤为令人印象深刻。早期测试在多个浏览器中渲染了完整的《了不起的盖茨比》（The Great Gatsby），以验证针对大量文本的估算测量是否准确。随后，corpora/ 文件夹也加入了测试，使用相同的技术对泰语、中文、韩语、日语、阿拉伯语等多种语言的冗长公共领域文档进行验证。

I learned that the OSV.dev open source vulnerability database has an open CORS JSON API so I had Claude Code build this HTML tool for pasting in a pyproject.toml or requirements.txt file (or name of a GitHub repo containing those) and seeing a list of all reported vulnerabilities from that API.

我了解到 OSV.dev（开源漏洞数据库）提供了一个开放的 CORS JSON API（跨域资源共享 JSON 接口），因此我让 Claude Code 构建了这款 HTML 工具，用于粘贴 pyproject.toml（Python 项目配置文件）或 requirements.txt（依赖文件）的内容（或包含这些文件的 GitHub 仓库名称），从而查看该 API 返回的所有已报告漏洞列表。
