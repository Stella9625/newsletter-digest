iNaturalist Sightings

iNaturalist 观察记录

Tool: iNaturalist Sightings

工具：iNaturalist 观察记录

I wanted to see my iNaturalist observations - across two separate accounts - grouped by when they occurred. I'm camping this weekend so I built this entirely on my phone using Claude Code for web.

我想查看自己在两个不同账号上的 iNaturalist 观察记录，并按发生时间进行分组。这个周末我在露营，因此完全通过手机，使用 Claude Code for web 构建了这个工具。

I started by building an inaturalist-clumper Python CLI for fetching and "clumping" observations - by default clumps use observations within 2 hours and 5km of each other.

我首先构建了一个名为 inaturalist-clumper 的 Python CLI（命令行界面）工具，用于获取并将观察记录进行“clumping（聚类）”——默认情况下，聚类会将彼此在 2 小时和 5 公里范围内的观察归为一组。

Then I setup simonw/inaturalist-clumps as a Git scraping repository to run that tool and record the result to clumps.json.

接着，我将 simonw/inaturalist-clumps 配置为一个 Git scraping（Git 抓取）仓库，用于运行该工具并将结果记录到 clumps.json 中。

That JSON file is hosted on GitHub, which means it can be fetched by JavaScript using CORS.

该 JSON（JavaScript 对象表示法）文件托管在 GitHub 上，这意味着可以通过 JavaScript 使用 CORS（跨域资源共享）获取。

Finally I ran this prompt against my simonw/tools repo:

最后，我在我的 simonw/tools 仓库中运行了如下提示词：

Build inat-sightings.html - an app that does a fetch() against https://raw.githubusercontent.com/simonw/inaturalist-clumps/refs/heads/main/clumps.json and then displays all of the observations on one page using the https://static.inaturalist.org/photos/538073008/small.jpg small.jpg URLs for the thumbnails - with loading=lazy - but when a thumbnail is clicked showing the large.jpg in an HTML modal. Both small and large should include the common species names if available

构建一个 inat-sightings.html 文件——一个应用，通过 fetch() 请求 https://raw.githubusercontent.com/simonw/inaturalist-clumps/refs/heads/main/clumps.json，然后在一页中展示所有观察记录，使用 https://static.inaturalist.org/photos/538073008/small.jpg 的 small.jpg URL 作为缩略图，并添加 loading=lazy（懒加载）属性；但当点击缩略图时，在一个 HTML modal（弹窗）中显示 large.jpg 大图。small 和 large 两种尺寸在可能的情况下都应包含物种常见名称。

Build inat-sightings.html - an app that does a fetch() against https://raw.githubusercontent.com/simonw/inaturalist-clumps/refs/heads/main/clumps.json and then displays all of the observations on one page using the https://static.inaturalist.org/photos/538073008/small.jpg small.jpg URLs for the thumbnails - with loading=lazy - but when a thumbnail is clicked showing the large.jpg in an HTML modal. Both small and large should include the common species names if available

构建一个 inat-sightings.html 文件——一个应用，通过 fetch() 请求 https://raw.githubusercontent.com/simonw/inaturalist-clumps/refs/heads/main/clumps.json，然后在一页中展示所有观察记录，使用 https://static.inaturalist.org/photos/538073008/small.jpg 的 small.jpg URL 作为缩略图，并添加 loading=lazy（懒加载）属性；但当点击缩略图时，在一个 HTML modal（弹窗）中显示 large.jpg 大图。small 和 large 两种尺寸在可能的情况下都应包含物种常见名称。

Codex CLI 0.128.0 adds /goal
CodexAI编程目标循环CLI
Codex CLI 0.128.0版本新增/goal指令，支持用户设定目标后让编码代理自动循环执行任务，直至目标达成或配置的token预算耗尽。该功能主要通过在每轮对话结束时自动注入特定的goals提示词文件来实现。
The latest version of OpenAI's Codex CLI coding agent adds their own version of the Ralph loop: you can now set a /goal and Codex will keep on looping until it evaluates that the goal has been completed... or the configured token budget has been exhausted.
OpenAI 的 Codex CLI 编码代理最新版本加入了他们自己的 Ralph 循环实现：你现在可以设置一个 /goal，Codex 会持续循环执行，直到它判定目标已完成……或者配置的 token 预算已耗尽。
It looks like the feature is mainly implemented though the goals/continuation.md and goals/budget_limit.md prompts, which are automatically injected at the end of a turn.
该功能似乎主要通过 goals/continuation.md 和 goals/budget_limit.md 这两个提示词实现，它们会在每轮对话结束时自动注入。

Codex CLI 0.128.0 adds /goal (via) The latest version of OpenAI's Codex CLI coding agent adds their own version of the Ralph loop: you can now set a /goal and Codex will keep on looping until it evaluates that the goal has been completed... or the configured token budget has been exhausted.

Codex CLI 0.128.0 新增了 /goal 命令（来源）。OpenAI 最新版本的 Codex CLI coding agent（编码智能体）加入了其自有的 Ralph loop（拉尔夫循环） 实现：你现在可以设置一个 /goal，Codex 将持续循环执行，直到它评估认为目标已完成……或者配置的 token budget（令牌预算） 耗尽为止。

It looks like the feature is mainly implemented through the goals/continuation.md and goals/budget_limit.md prompts, which are automatically injected at the end of a turn.

该功能似乎主要通过 goals/continuation.md 和 goals/budget_limit.md 这两个 prompt（提示词） 来实现，它们会在每一轮 turn（对话轮次） 结束时自动注入。
