Microsoft Copilot Cowork Exfiltrates Files

Microsoft Copilot Cowork 被曝出存在数据外泄漏洞，AI 代理可未经审批向用户发送包含外部图片的邮件，用户打开时即可能泄露数据；更严重的是，攻击者还可通过提示注入获取 OneDrive 预认证下载链接，进而窃取用户文件。
Microsoft Copilot Cowork (yes, that's a real product name) was allowing agents to send emails to the user's own inbox without approval...
微软 Copilot Cowork（是的，这确实是个真实的产品名称）允许代理在未经批准的情况下向用户自己的收件箱发送邮件……

Microsoft Copilot Cowork Exfiltrates Files

In this case Microsoft Copilot Cowork (yes, that'sa real product name) was allowing agents to send emails to the user's own inbox without approval... but those messages were then displayed in a way that could leak data to an attacker via rendered images:

在这种情况下，Microsoft Copilot Cowork（是的，这是一个真实的产品名）允许智能体（agents）在未经批准的情况下向用户自己的收件箱发送电子邮件……但这些消息随后以某种方式显示，可能通过渲染的图片将数据泄露给攻击者：

Because these messages can contain external images that trigger network requests to external websites, data can be exfiltrated when a user opens a compromised message sent by the agent.
因为这些消息可能包含触发向外部网站发起网络请求（network requests）的外部图片，当用户打开由智能体发送的被篡改（compromised）消息时，数据可能被外泄（exfiltrated）。
Because these messages can contain external images that trigger network requests to external websites, data can be exfiltrated when a user opens a compromised message sent by the agent.

因为这些消息可能包含触发向外部网站发起网络请求的外部图片，当用户打开由智能体发送的被篡改消息时，数据可能被外泄。

Since OneDrive can create pre-authenticated download links, a successful prompt injection could cause those links to be leaked, allowing files to be downloaded by the attacker.

由于 OneDrive 可以创建预认证（pre-authenticated）下载链接，一次成功的提示注入（prompt injection）可能导致这些链接被泄露，从而使攻击者能够下载文件。
