Microsoft's new MAI models
微软大模型代码模型轻量模型
微软新发布了MAI-Thinking-1与MAI-Code-1-Flash两款轻量级大模型，分别聚焦推理与代码场景。不同于当前主流做法，微软强调这两款模型完全基于商业授权的干净数据从头独立训练，未对第三方模型进行蒸馏。
It's very interesting to see Microsoft releasing models with such low parameter counts, especially given how expensive larger models are to access right now.
微软推出参数如此精简的模型，这一点非常有趣——尤其是在当下访问大模型的成本居高不下的情况下。
I would very much like to learn more about this 'appropriately licensed' data! Could these be the first generally useful code-specialist models that didn't train on an unlicensed dump of the web?
我非常想进一步了解这些'授权得当'的数据！它们会不会是第一批没有使用未授权网络数据Dump来训练的、真正实用的代码专用模型？

Microsoft's new MAI models / 微软全新 MAI 模型

Microsoft announced two new text LLMs this morning — MAI-Thinking-1 (reasoning, 35B parameters, available to "select early partners") and MAI-Code-1-Flash (5B parameters, "purpose-built for GitHub Copilot and VS Code to deliver high performance and lower cost [...] rolling out to GitHub Copilot individual users in Visual Studio Code"). I've not been able to try either of them just yet.

微软（Microsoft）今早发布了两款全新的文本 LLM（大语言模型，Large Language Model）——MAI-Thinking-1（推理模型，350亿参数，面向"精选早期合作伙伴"开放）和 MAI-Code-1-Flash（50亿参数，"专为 GitHub Copilot 和 VS Code 打造，以提供高性能和更低成本 [...] 正在向 Visual Studio Code 中的 GitHub Copilot 个人用户推出"）。我目前还没能上手体验这两款模型。

It's very interesting to see Microsoft releasing models with such low parameter counts, especially given how expensive larger models are to access right now. They claim MAI-Thinking-1 "is preferred to Sonnet 4.6 in our blind human side-by-side evaluations", which is impressive for a 35B model seeing as I frequently run models larger than that on my own laptop.

看到 微软（Microsoft）推出参数量（parameter counts）如此低的模型非常有趣，尤其是考虑到目前访问更大模型的成本有多高昂。他们声称 MAI-Thinking-1 "在盲测人类横向对比评估中优于 Sonnet 4.6"，这对于一个350亿参数的模型来说令人印象深刻，毕竟我自己在笔记本上经常运行的模型都比它大。

Also of note:

同样值得注意的是：

We trained [MAI-Thinking-1] from the ground up on enterprise grade, clean and commercially licensed data, without distillation from third-party models.

我们从零开始训练 [MAI-Thinking-1]，使用 企业级（enterprise grade）、干净且具备商业许可的数据，且未采用第三方模型的 知识蒸馏（distillation）技术。

We trained [MAI-Thinking-1] from the ground up on enterprise grade, clean and commercially licensed data, without distillation from third-party models.

我们从零开始训练 [MAI-Thinking-1]，使用企业级（enterprise grade）、干净且具备商业许可的数据，且未采用第三方模型的知识蒸馏（distillation）技术。

And for MAI-Code-1-Flash as well:

对于 MAI-Code-1-Flash 同样如此：

It is built end-to-end by Microsoft using clean and appropriately licensed data.

该模型由 微软（Microsoft） 端到端（end-to-end）构建，使用了干净且获得适当授权的数据。

It is built end-to-end by Microsoft using clean and appropriately licensed data.

该模型由 微软（Microsoft） 端到端（end-to-end）构建，使用了干净且获得适当授权的数据。

I would very much like to learn more about this "appropriately licensed" data! Could these be the first generally useful code-specialist models that didn't train on an unlicensed dump of the web?

我非常想进一步了解这些"获得适当授权"的数据！这些模型会不会是首批在未经网络非法抓取（unlicensed dump）的数据上训练、且具备广泛实用价值的 代码专用模型（code-specialist models）？
