asgi-gzip 0.3 发布
🧪 实验记录
asgi-gzip 0.3
ASGIGzipPythonBug修复
asgi-gzip发布0.3版本，修复了Server-Sent Events (SSE) 流响应被错误压缩的问题。此次更新补上了因GitHub Actions工作流中断而遗漏的Starlette上游修复。
I ran into trouble deploying a new feature using SSE to a production Datasette instance, and it turned out that instance was using datasette-gzip which uses asgi-gzip which was incorrectly compressing event/text-stream responses.
我在使用 SSE 向生产环境 Datasette 实例部署新功能时遇到了麻烦，结果发现该实例使用了 datasette-gzip，而后者依赖的 asgi-gzip 错误地压缩了 event/text-stream 响应。
asgi-gzip was extracted from Starlette, and has a GitHub Actions scheduled workflow to check Starlette for updates that need to be ported to the library... but that action had stopped running and hence had missed Starlette's own fix for this issue.
asgi-gzip 是从 Starlette 中提取出来的，本有一个 GitHub Actions 定时工作流来检查 Starlette 的更新并移植到该库……但该操作已停止运行，因此错过了 Starlette 对此问题的修复。

Release: asgi-gzip 0.3

发布：asgi-gzip 0.3

I ran into trouble deploying a new feature usingSSE(Server-Sent Events) to a productionDatasetteinstance, and it turned out that instance was usingdatasette-gzipwhich usesasgi-gzipwhich was incorrectly compressing event/text-stream responses.

我在向生产环境的Datasette实例部署一个使用SSE（Server-Sent Events，服务器发送事件）的新功能时遇到了麻烦，结果发现该实例使用了datasette-gzip，而它依赖的asgi-gzip错误地压缩了 event/text-stream 响应。

asgi-gzipwas extracted fromStarlette, and hasa GitHub Actions scheduled workflowto check Starlette for updates that need to be ported to the library... but that action had stopped running and hence had missedStarlette's own fixfor this issue.

asgi-gzip是从Starlette中提取出来的，并且有一个GitHub Actions 定时工作流（scheduled workflow）来检查 Starlette 的更新并将其移植到该库中……但该操作已停止运行，因此错过了Starlette 对此问题的修复。

I ran the workflow and integrated the new fix, and nowdatasette-gzipandasgi-gzipboth correctly handletext/event-streamin SSE responses.

我运行了该工作流并集成了新的修复，现在datasette-gzip和asgi-gzip都能正确处理 SSE 响应中的text/event-stream类型。

Monarch: an API to your supercomputer (11 minute read)

Monarch is a distributed programming framework for PyTorch that makes running distributed training jobs on huge clusters easy. It makes clusters programmable through a simple Python API that exposes the supercomputer as a coherent, directly controllable system. Monarch is optimized for agentic usage, and it provides consistent infrastructure abstractions and exposed telemetry. It can turn a dev machine into a supercomputer, leveling up its agents.

Monarch 是一个针对 PyTorch 的分布式编程框架，可简化在大型集群上运行分布式训练任务的过程。它通过简单的 Python API 使集群可编程，将超级计算机暴露为一个连贯、可直接控制的系统。Monarch 针对智能体使用（agentic usage）进行了优化，提供一致的基础设施抽象和暴露的遥测数据。它可以将开发机器转变为超级计算机，提升其智能体的能力。
